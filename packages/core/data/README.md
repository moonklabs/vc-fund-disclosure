# 번들 시드 데이터

바이너리에 임베드되어 `vc-funds import seed` 및 `vc-funds setup` 부트스트랩에서 사용되는 공공 개방 데이터입니다.

## datago-kvic-mofund-operators-20251212.csv

| 항목 | 내용 |
|---|---|
| 데이터셋 | 한국벤처투자_모태펀드 자조합 운용사정보_20251212 |
| 출처 | 한국벤처투자(KVIC), 공공데이터포털 — https://www.data.go.kr/data/3060708/fileData.do |
| 라이선스 | 이용허락범위 제한 없음 (공공데이터포털 명시) |
| 수집일 | 2026-07-07 (원본 게시 2025-12-15) |
| 내용 | 모태펀드 자조합 대표운영사 1,411행 (고유 운용사 327개), 운영사구분, 자조합 규모(백만원) |
| 가공 | CP949 → UTF-8 인코딩 변환만 수행, 내용 무변경 |

이 파일은 공식 소스가 아닌 **스냅샷 사본**입니다. 최신 데이터는 위 공공데이터포털 링크에서 확인하세요.

주의: `자조합 규모` 컬럼 단위는 **백만원**이며, 펀드 개별 식별자가 없는 운용사 목록이므로 import 시 investors 테이블만 적재됩니다 (funds 미생성).
